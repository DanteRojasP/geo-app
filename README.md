# NASA_CLAUDE_TEAM
This it´s a project based on the NASA hackaton from 2026, date released Nov. 14th - 15th.

## Firewatch Perú

La rama `dante` incluye el observatorio cartográfico desarrollado con React, Vite y MapLibre.

```bash
npm install
npm run dev
```

Para producción, configura `FIRMS_MAP_KEY` en el proveedor de despliegue y ejecuta `npm run build`. El resultado estático se genera en `dist/`.
